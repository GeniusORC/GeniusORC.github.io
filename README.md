# 陈剑波 · 个人学术主页

基于极简学术风格设计的静态个人主页，部署于 GitHub Pages。

仓库：<https://github.com/GeniusORC/GeniusORC.github.io> ｜ 站点：<https://geniusorc.github.io/>

## 文件结构

```text
index.html             中文主页结构、内容与全部样式（可直接编辑）
cv.html                英文简历页面（可直接编辑）
assets/profile.svg     姓名缩写标识（可替换为个人照片）
DEPLOY.md              GitHub Pages 部署步骤
README.md              本说明
```

## 内容来源

页面内容根据个人简历整理。简历中未提供的栏目（如 Google Scholar、ORCID、具体院系）未编造；联系邮箱、电话与 GitHub 账号均来自简历或仓库信息。

参考了 `Xin-Jiaqi/minimal-academic-homepage` 的极简排版与视觉语言，页面代码为独立重写。该模板仓库未声明开源许可，因此未直接复制其源码或素材。

## 修改方式

直接用文本编辑器打开 `index.html` 修改对应文字、链接与 `assets/` 中的标识文件即可。无需安装依赖或执行构建命令。
